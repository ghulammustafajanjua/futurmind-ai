Free QR Code Generator

Create a QR code for a website, WhatsApp chat, Wi-Fi network, email, phone number or any text. Download it as PNG or SVG. Free, no sign-up, and it never expires.

Use digits only, starting with the country code (971 for UAE, 92 for Pakistan, 91 for India). No + or leading 0.

🔒 Your QR code is made in your browser. We do not store or track it, and it never expires.

How to make a QR code

  1. Choose the type: website link, WhatsApp, Wi-Fi, email, phone or plain text.
  2. Fill in the details. The QR code updates instantly as you type.
  3. Pick colours and size if you like. Keep a dark code on a light background so every phone can scan it.
  4. Test it by pointing your phone camera at the screen, then press Download PNG or Download SVG.

Does this QR code expire?

No. Many "free" QR websites create a dynamic QR code that points to their own server first. When the free trial ends, the code stops working, even if it is already printed on your menu or business cards. This tool makes a static QR code: the information is stored inside the code itself, so it works for ever and nobody can switch it off. The only thing to remember is that you cannot change a static code later, so check the link before you print.

Ideas for using QR codes

  • Shops and restaurants: a WhatsApp QR code on the counter lets customers message you with one scan.
  • Guests at home or in the office: a Wi-Fi QR code connects phones without typing the password.
  • Business cards and flyers: link to your website, Instagram or Google Maps location.
  • YouTube creators: show a QR code in your video or on printed merchandise that links to your channel.

PNG or SVG?

PNG is an image that works everywhere: WhatsApp, Word, Canva and social media. SVG stays perfectly sharp at any size, so it is the best choice for printing on banners, packaging and large posters. For printing, also choose High error correction, which helps the code scan even if it gets a little scratched or dirty.

Frequently asked questions

Is this QR code generator really free?

Yes. It is completely free with no sign-up, no watermark and no limit on how many QR codes you make.

Will my QR code stop working?

No. This tool makes static QR codes that store your information inside the code, so they never expire and do not depend on our website.

Can you see my Wi-Fi password or data?

No. The QR code is created in your own browser. Your Wi-Fi password, links and text are not sent to our server or saved.

How do I make a WhatsApp QR code?

Choose "WhatsApp", enter your number with the country code using digits only (for example 971501234567), and add an optional message. When someone scans it, WhatsApp opens a chat with you.

Can I change the link after printing the QR code?

No. Static QR codes cannot be edited after you make them. Always test the code with your phone before printing it.
